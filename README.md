# Personal Portfolio Website

A single-page responsive personal portfolio built with semantic HTML5 and custom CSS.

## Features
- **Semantic Structure**: Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **Responsive Layout**: Designed with Flexbox, CSS Grid, and media queries for mobile optimization.
- **Embedded Media**: Includes responsive project images, demo video, and interactive Google Maps `<iframe>`.
- **Contact Form**: Complete accessible web form with input validation and fieldsets.
